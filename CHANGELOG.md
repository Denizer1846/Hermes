# История изменений

## 2.0.0-alpha.10 — октябрь 2026

- Обновлённый интерфейс и фирменное оформление «Гермеса».
- Генерация отдельных DOCX и PDF по Word-шаблону.
- Импорт списков студентов, включая PDF с текстовым слоем.
- Настройка исключаемых дней и группировка документов в папки по месяцам.
- Переработанный установщик Windows и проверенный сценарий обновления с alpha.9.
- Улучшенные сообщения об ошибках и проверки качества.

## 2.0.0-alpha.9

- Предыдущая версия настольной программы для автоматического создания документов.

> Публикация истории изменений не означает, что все перечисленные версии доступны для публичной загрузки. Официальные файлы публикуются в [Releases](https://github.com/Denizer1846/Hermes/releases).
