## О приложении

**«Гермес»** — настольное приложение для автоматизации повседневной работы с образовательными документами.

Программа помогает преподавателям и сотрудникам образовательных организаций формировать документы для студентов без ручного заполнения одинаковых шаблонов.

Достаточно указать необходимый период, добавить список студентов, выбрать шаблон Word и папку сохранения.

Остальную работу «Гермес» выполнит автоматически.

## Возможности

| Возможность | Описание |
| --- | --- |
| **Настройка периода** | Выбор месяца и года, исключение выходных дней, отдельных дат и диапазонов |
| **Списки студентов** | Добавление, редактирование и удаление записей |
| **Импорт данных** | Загрузка списков из Excel, Word, TXT и текстовых PDF |
| **Шаблоны документов** | Использование стандартного или собственного шаблона DOCX |
| **Формирование DOCX** | Создание отдельного документа Word для каждого студента |
| **Формирование PDF** | Преобразование документов в PDF с использованием Microsoft Word или LibreOffice |
| **Организация файлов** | Автоматическое размещение результатов в папке месяца и года |
| **Локальная работа** | Подготовка документов на компьютере без обязательной регистрации |
| **Удобное управление** | Графический интерфейс с отображением этапов формирования документов |

> Для формирования PDF требуется установленный Microsoft Word или LibreOffice. Для импорта сканированных PDF без текстового слоя необходимо предварительное распознавание текста.

## Начало работы

### 1. Установка

Скачайте установщик приложения для Windows:

**[Скачать Гермес 2.0.0-alpha.10](https://github.com/Denizer1846/Hermes/releases/download/v2.0.0-alpha.10/HermesDocuments_Setup_2.0.0-alpha.10.exe)**

Запустите установочный файл и следуйте инструкциям.

Для обычного использования не требуется устанавливать Python, Node.js или другие средства разработки.

### 2. Настройка периода

Выберите месяц и год, для которых необходимо подготовить документы.

При необходимости исключите субботы, воскресенья и дополнительные даты.

### 3. Добавление студентов

Добавьте студентов вручную или загрузите существующий список из поддерживаемого формата.

Проверьте фамилии, инициалы и учебные группы.

### 4. Формирование документов

Выберите шаблон Word, формат готовых документов и папку для сохранения.

Запустите формирование и дождитесь завершения.

### 5. Получение результатов

Готовые документы сохраняются в выбранном каталоге с группировкой по месяцу и году.

После завершения обработки можно открыть папку с результатами.

## Конфиденциальность

«Гермес» ориентирован на локальную обработку документов.

Списки студентов используются для формирования документов. Сохранение списка в отдельный файл выполняется по выбору пользователя.

Приложение не требует обязательной регистрации для выполнения основных операций.

Пользователь самостоятельно определяет место хранения результатов и отвечает за соблюдение требований к обработке и защите персональных данных.

Подробнее: [Конфиденциальность](docs/PRIVACY.md).
