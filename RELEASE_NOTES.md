# Гермес 2.0.0-alpha.10

Первый публичный предварительный выпуск «Гермеса» — настольного приложения экосистемы «Мысль» для автоматического создания студенческих документов по шаблону Word.

## В этом выпуске

- Настройка месяца, года и исключаемых дней.
- Импорт списков студентов из Excel, Word, TXT и текстовых PDF.
- Генерация DOCX и PDF с сохранением в папку месяца и года.
- Обновлённый интерфейс, Анастасия и фирменный установщик Windows.

## Установка

Скачайте файл **HermesDocuments_Setup_2.0.0-alpha.10.exe** в разделе Assets и запустите его на Windows.

Для создания PDF требуется установленный Microsoft Word или LibreOffice. Сведения об установке и работе приведены в документации репозитория.

**Статус:** предварительная версия (alpha). При обнаружении ошибок сообщайте правообладателю. Исходный код не публикуется.
