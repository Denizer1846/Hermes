# Обратная связь

«Гермес» — закрытый программный продукт экосистемы «Мысль».
Исходный код хранится в отдельном приватном репозитории.

Этот публичный репозиторий предназначен для официальных установочных выпусков,
пользовательской документации и сообщений об ошибках или предложений.

**Патчи, pull request с изменениями программы и сторонние сборки не принимаются.**
Общие условия использования: [docs/RIGHTS.md](docs/RIGHTS.md).

Сообщить об ошибке или предложить улучшение можно через
[Issues](https://github.com/Denizer1846/Hermes/issues/new/choose).
Не публикуйте реальные списки студентов и другие персональные данные.
