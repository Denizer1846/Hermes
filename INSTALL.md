# Установка и обновление

## Установка

1. Откройте [официальный раздел Releases](https://github.com/Denizer1846/Hermes/releases).
2. Скачайте установщик **HermesDocuments_Setup_*.exe** из материалов опубликованного выпуска.
3. Запустите файл и пройдите мастер установки.
4. Запустите «Гермес» с рабочего стола или через меню «Пуск».

Python, Node.js и среда программирования пользователю не нужны.

## Системные требования

- **Windows** — приложение проверялось в Windows 11.
- Для создания PDF требуется **Microsoft Word либо LibreOffice**.
- Для формирования DOCX отдельный конвертер не требуется.

## Обновление

Закройте приложение и запустите новый официальный установщик. Обновление с предыдущей версии Talony / «Гермес» проверялось при разработке. Перед обновлением рекомендуем сделать резервную копию ценных документов и пользовательских списков.

## Безопасность установщика

Установщик без цифровой подписи может вызывать предупреждение Windows SmartScreen. Загружайте программу только из официального репозитория и не запускайте файлы сомнительного происхождения.
