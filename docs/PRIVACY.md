# Конфиденциальность данных

«Гермес» предназначен для локальной подготовки документов. Приложение работает со списками студентов (фамилии, инициалы и группы), датами, путями к шаблону и папкам сохранения.

Обычный сценарий создания документов не требует передачи этих данных разработчику или регистрации в облачном сервисе. Пользователь самостоятельно выбирает, где хранить сохранённые списки и сформированные документы.

**Ответственность пользователя:** соблюдение требований законодательства о персональных данных, ограничение доступа к созданным файлам, организация резервных копий и безопасная передача документов третьим лицам.

Для публичных демонстраций используйте вымышленные сведения о студентах.
