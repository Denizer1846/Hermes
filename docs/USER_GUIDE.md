# Руководство пользователя

«Гермес» помогает создавать отдельные документы студентам по шаблону Word.

## Период

Выберите месяц и год. Включите исключение суббот и воскресений, если требуется. Для дополнительных пропущенных дат используйте, например, запись **5, 12–14, 28**. Проверьте итоговое число рабочих дней.

## Список студентов

Добавьте фамилию с инициалами и учебную группу. Строки можно редактировать, выбирать и удалять. Можно импортировать готовый список из **Excel, Word, TXT и PDF с текстовым слоем**. Сканы PDF без распознанного текста не поддерживаются для прямого импорта.

При необходимости сохраните список в выбранный файл. Не используйте реальные персональные данные для демонстрационных скриншотов.

## Шаблон и папка

Проверьте Word-шаблон, при необходимости выберите другой. Укажите каталог сохранения. Прежде чем создавать документы для всего списка, сформируйте несколько тестовых файлов.

## Формат

- **DOCX** — отдельный документ Word для каждого студента.
- **PDF** — отдельный PDF для каждого студента; необходим Microsoft Word или LibreOffice для преобразования.

## Создание

Нажмите «Создать документы», дождитесь сообщения об успехе и откройте папку результатов. Документы группируются в подкаталоге с названием месяца и года, например **Октябрь 2026**.

## При ошибке

Проверьте доступность шаблона и каталога, корректность введённых строк и права записи. Для PDF проверьте установленный конвертер и отсутствие блокировки файла другим приложением.
